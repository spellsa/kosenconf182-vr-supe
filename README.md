## 交流ブース
交流ブースのモデリングおおよそ全てと、1ブースの作成を担当しました。
各ブースごとに大まかなテーマを決めており、それぞれフィリピン、オランダ、日本のようになっています。
VRらしさを演出するため、空飛ぶクジラが配置されています。
<img width="1447" height="830" alt="Image" src="https://github.com/user-attachments/assets/844b36c2-0247-458e-9b24-69c484ee3177" />

オランダの建物を少し参考にしています。地面にはチューリップを多く配置しています。
<img width="1061" height="646" alt="Image" src="https://github.com/user-attachments/assets/325ef3bd-2e54-47c8-9d79-7447f6b74a6f" />

私は釣りブースを担当しました。
この鉛筆を模した釣り竿は私のお気に入りです。釣り竿を長押しして話すことで竿を投げることができます。また、魚が近づいているかどうかは水紋のエフェクトで確認することができ、
クリックで釣り上げることができます。

釣り上げたものは一定時間釣ったプレイヤーの頭上に追従するようになります。これらは複数プレイヤー間でも正しく表示され、座標も同期されます。
